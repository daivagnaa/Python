# DeepSeek Chatbot

This project is a chatbot application that utilizes the DeepSeek API to provide conversational capabilities. It serves as a demonstration of how to integrate with the DeepSeek API and can be extended with additional features and functionalities.

## Project Structure

```
deepseek-chatbot
├── src
│   ├── main_bot.py       # Main entry point for the chatbot application
│   └── utils.py          # Utility functions for the chatbot
├── requirements.txt      # List of dependencies
└── README.md             # Project documentation
```

## Setup Instructions

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd deepseek-chatbot
   ```

2. **Install dependencies:**
   Make sure you have Python installed, then run:
   ```
   pip install -r requirements.txt
   ```

3. **Set up your API key:**
   Replace the placeholder in `main_bot.py` with your actual DeepSeek API key.

## Usage Guidelines

To run the chatbot, execute the following command:
```
python src/main_bot.py
```

This will initialize the chatbot and send a greeting message. You can modify the messages in `main_bot.py` to interact with the chatbot differently.
